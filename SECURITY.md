# Security

Report a vulnerability by email to security@oaiz.io. Do not open a public issue or pull request.

This policy covers the packages in this repository; a vulnerability in the OAIZ platform itself goes
to the same address.

Include the package and version, what an attacker can do, and the steps to reproduce it. OAIZ
reviews every report and credits you for the report unless you ask not to be named.

Only the latest version of each package receives fixes.
